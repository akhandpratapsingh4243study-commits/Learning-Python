# Mechatronics Engineering Preparation Portfolio

Welcome to my software development repository. I built these Python applications to master foundational computer science principles and algorithmic logic, proactively preparing for the rigorous **Mechatronics Engineering** curriculum at Fontys University of Applied Sciences.

## 📁 Portfolio Projects

### 1. Caesar Cipher Tool (`caesar_cipher.py`)
* **Description:** A text encryption and decryption script utilizing the classic Caesar Cipher shifting algorithm.
* **Core Concepts:** String manipulation, character mapping, loops, and custom functions.

### 2. Movie Ticket Booking Calculator (`Movie_ticket_booking_calculator.py`)
* **Description:** An automated pricing tool that calculates ticket costs based on user inputs, seat tiers, and age restrictions.
* **Core Concepts:** Data type conversion (casting strings to integers/floats), arithmetic operations, and complex nested conditionals.

### 3. Employee Profile Generator (`employee_profile_generator.py`)
* **Description:** A program that collects, formats, and displays structured professional profile data from user prompts.
* **Core Concepts:** Terminal input/output formatting, variable assignment, and string interpolation.

### 4. Bill Splitter (`Bill_splitter.py`)
* **Description:** A utility calculator designed to split group bills evenly while factoring in variable tax and tip percentages.
* **Core Concepts:** Floating-point math accuracy, percentage calculations, and output formatting.

### 5. User Input Classifier (`user_input_classifier.py`)
* **Description:** A conversational logic script that captures demographics (age and gender) to route users through customized decision trees.
* **Core Concepts:** Conditional logic (`if`/`elif`/`else`), logical operators (`and`/`or`), and input validation.

## ⚙️ Technical Skills Demonstrated
* **Control Flow:** Designing robust decision-making logic inside software applications.
* **Data Handling:** Collecting, sanitizing, and processing user inputs dynamically.
* **Version Control:** Managing software files and code updates using professional Git workflows.
